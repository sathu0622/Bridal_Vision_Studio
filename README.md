# Bridal Vision Studio

### Bridal E-Commerce & Virtual Try-On Platform

Bridal Vision Studio is a full-stack e-commerce platform developed as a third-year academic project at SLIIT. It combines online bridal shopping with virtual jewelry try-on and personalized product recommendations.

## Features

- Product listings for browsing bridal products.
- Shopping cart, user authentication, and payment integration.
- Virtual jewelry try-on using OpenCV.
- Skin-tone-based product recommendations.
- Customer reviews and feedback.
- Responsive interfaces connected to backend services through REST APIs.

## Technology Stack

| Area | Technologies |
| --- | --- |
| Frontend | React.js, JavaScript |
| Backend | Node.js, Express.js |
| Database | MongoDB |
| Computer vision | OpenCV |
| Application integration | REST APIs |
